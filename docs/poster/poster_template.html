MediScribe회진에 동행하는 진료 요약 로봇

MediScribe 팀남윤상 · 김진찬 · 지민선 · 김해인

회진은 5분 안에 끝나고, 차트는 환자가 볼 수 없습니다. MediScribe는 의사–환자 대화를 듣고 환자가 가져갈 설명문을 만들어 의사가 검수한 내용만 그 자리에서 종이와 QR로 전달합니다. 음성인식·요약·주행이 모두 로봇 안에서 돌아가 대화는 병원 밖으로 나가지 않습니다.

개발 배경 — 설명은 말로 한 번 끝난다
  • 회진은 대개 5분 이내. 환자는 약 용량·재검 일정·위험 신호를 기억하지 못한 채 병실을 나선다.
  • 차트는 의료진만 본다. 환자가 자기 진료 내용을 다시 확인할 경로가 없다. 고령 환자와 보호자는 더 어렵다.

→ 설명이 끝나는 그 자리에서, 환자가 손에 쥘 종이 한 장을 만든다.

작동 방식 — 8단계 파이프라인
__PIPE__

임상 내용이 없는 발화는 모델에 보내지 않고, 원문에 없는 숫자가 섞인 줄은 버린다. 모델이 흘린 용량·일정·경고는 규칙이 원문에서 직접 회수한다. 전 구간 Jetson Orin NX 16GB 온디바이스.

자율주행 — 엔코더 없는 차량의 SLAM
복도 + 직각 코너
교차 복도 + 병실 입구

수동 주행 한 번으로 작성한 점유격자 지도. 보라색이 벽, 청록색이 주행 궤적. 바퀴 엔코더가 없어 매 스캔의 지도 정합 결과를 오도메트리로 사용한다. ROS2 없이 순수 Python 구현.

로봇 플랫폼
외관 상부 장비함 · 전방 2D 라이다
내부 Jetson · 제어 보드 · 배터리

1/5 스케일 애커만 조향 차량. Jetson Orin NX 16GB, 2D 라이다(STL-27L), 깊이 카메라(RealSense D435), 6채널 마이크 어레이, 배터리를 싣고 하위 제어는 Arduino Mega가 맡는다.

의사 말만 듣는다 — 얼굴 방위각 × 음원 방향

RealSense 컬러에서 얼굴을 찾아 등록 DB와 대조해 이름까지 식별하고, 뎁스로 방위각과 거리를 잰다. 마이크가 추정한 음원 방향과 일치할 때만 "의사 발화"로 보고 요약에 넣는다. 두 센서의 0점이 달라 1회 캘리브레이션으로 맞춘다.

차별점
1
로봇 안에서 끝난다. 외부 서버 전송이 없어 대화 원문이 병원을 벗어나지 않고, 인터넷이 없는 구역에서도 동작한다.
2
모델을 믿지 않는다. 원문에 없는 숫자는 코드가 버리고, 모델이 흘린 용량·일정·경고는 코드가 원문에서 직접 회수한다.
3
의사가 승인해야 나간다. 검수 전에는 인쇄·QR이 모두 차단된다. 사람이 책임지는 지점을 코드로 고정했다.
활용 방안 및 기대효과
· 환자 — 설명을 종이로 가져간다. 복약 순응도와 재방문 일정 준수가 올라간다.   · 보호자 — 회진에 함께 있지 못해도 같은 내용을 공유받는다.
· 의료진 — 같은 설명의 반복과 퇴원 후 문의가 줄고, 남는 기록은 의사가 승인한 내용뿐이다.   · 확장 — 투약 안내 · 퇴원 교육 · 검사 전 준비사항 안내로 넓힌다.
실제 생성 예시 — 의사가 말하면, 환자는 이 종이를 받는다
① 진료실에서 오간 말

의사“지난번 검사 결과부터 보겠습니다. 공복 혈당이 백팔십이고 당화혈색소가 팔점이 퍼센트입니다. 목표가 칠 퍼센트 아래라 조금 높아요.”

의사“메트포르민을 하루 오백에서 천 밀리그램으로 올리겠습니다. 아침저녁으로 한 알씩 식사와 함께 드세요.”

환자“속이 불편하면 어떡하죠?”

의사“대개 일주일이면 괜찮아집니다. 저혈당이 올 수 있으니 사탕을 꼭 가지고 다니세요. 식은땀이 나거나 어지러우면 바로 드시고요.”

의사“이 주 뒤에 혈액검사 다시 하고 결과 보고 조정하겠습니다.”

잡담은 임상 게이트가 걸러 모델에 가지 않는다. 한글 수사는 숫자로 바꿔 원문과 대조한다 — 백팔십→180, 팔점이→8.2, 천→1000.

② 의사 검수 — 실제 구동 캡처

인식 오류가 남은 줄을 의사가 고치고 승인한다. 승인 전에는 인쇄·QR 경로가 모두 403으로 차단된다.
