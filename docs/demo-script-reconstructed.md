## 환자 1 (demo-001) — 당뇨 외래

**대본 (의사 역)**

> 안녕하세요, 지난번 검사 결과부터 보겠습니다.
> 공복 혈당이 백팔십이고, 당화혈색소가 팔점이 퍼센트입니다.
> 목표가 칠 퍼센트 아래니까 조금 높은 편이에요.
> 메트포르민을 하루에 오백 밀리그램에서 천 밀리그램으로 올리겠습니다. 아침저녁으로 한 알씩 드세요.
> 약을 올리면 속이 좀 불편할 수 있는데, 대개 일주일이면 괜찮아집니다.
> 그리고 저혈당이 올 수 있으니 사탕을 꼭 가지고 다니세요. 식은땀이 나거나 어지러우면 바로 드시고요.
> 이 주 뒤에 혈액검사 다시 하고, 그 결과 보고 조정하겠습니다.

**기대 출력 (환자용 메모)**

```
■ 오늘 검사 결과
 - 공복 혈당 180
 - 당화혈색소 8.2% (목표 7% 미만)

■ 처방 / 약
 - 메트포르민 500mg → 1000mg 증량
 - 아침·저녁 1알씩

■ 주의하세요
 - 저혈당 대비해 사탕 휴대
 - 식은땀·어지럼 있으면 바로 섭취
 - 증량 초기 속쓰림 가능, 보통 1주 내 호전

■ 다음 진료
 - 2주 뒤 혈액검사 후 조정
```

## 환자 2 (demo-002) — 항응고제 시작

**대본 (의사 역)**

> 심방세동이 확인돼서 피가 굳지 않게 하는 약을 시작하겠습니다.
> 와파린인데, 하루 한 번 저녁에 삼 밀리그램 드세요.
> 이 약은 용량이 아주 중요해서, 아이엔알 수치를 보면서 맞춰갑니다. 오늘은 일점이입니다.
> 잇몸에서 피가 나거나, 멍이 크게 들거나, 대변이 까맣게 나오면 바로 오셔야 합니다.
> 비타민케이가 많은 시금치나 녹즙을 갑자기 많이 드시면 약효가 떨어집니다.
> 다음 주 화요일에 혈액검사 하러 오세요.

**기대 출력 (환자용 메모)**

```
■ 오늘 검사 결과
 - INR 1.2

■ 처방 / 약
 - 와파린 3mg, 하루 1회 저녁

■ 주의하세요
 - 잇몸 출혈 / 큰 멍 / 검은 변 → 즉시 내원
 - 시금치·녹즙 등 비타민K 급증 금지 (약효 저하)

■ 다음 진료
 - 다음 주 화요일 혈액검사
```

## 시연 때 강조할 점

1. **용량·일정·경고는 모델이 아니라 규칙이 뽑는다.** 2B 모델은 "와파린을 시작합니다"까지만 쓰고
   "하루 한 번 저녁 3밀리그램"을 흘린다 → `rule_facts()`가 원문에서 직접 확정 사실로 삽입.
   안전 보존율 34% → **98.1%**.
2. **원문에 없는 숫자는 버린다** (`grounded`). 한글 수사 변환 후 대조 (백팔십→180, 팔점이→8.2).
3. **잡담은 모델에 가지도 않는다** (임상 게이트, 잡담 21문장 전부 차단 확인).
4. **미검수 출력은 403.** 의사가 승인해야만 QR/인쇄가 열린다.
