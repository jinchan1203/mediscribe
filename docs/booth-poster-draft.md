**MediScribe — 회진에 동행하는 진료 요약 로봇**

부제 (28pt):
> 의사–환자 대화를 듣고 환자용 진료 요약을 만들어, 의사가 검수한 내용만 즉석에서 전달합니다.
> 모든 처리는 로봇 내부(Jetson Orin NX)에서 수행 — 대화는 병원 밖으로 나가지 않습니다.

소속 / 팀명 / 팀원 (24pt): 연세대학교 · YAD (Yonsei Autonomous Driving) · <팀원 이름>

## ① 개발 배경 — 왜 필요한가

- 외래·회진 설명은 **말로 한 번** 끝난다. 환자는 약 용량·재검 일정·위험 신호를 기억하지 못한 채 돌아간다.
- 의사가 설명 후 요약을 따로 적어주는 것은 **진료 시간상 불가능**하다.
- 기존 음성기록(AI 서기) 제품은 **의무기록용·클라우드 전송**이 전제다.
  → 환자에게 바로 주는 설명문이 아니고, 대화가 외부로 나간다.

**MediScribe가 푸는 문제**: 설명이 끝나는 그 자리에서, 환자가 가져갈 수 있는 종이 한 장을 만든다.

---

## ② 솔루션 — 무엇을 하는가

회진 동선을 따라 자율주행 → 대화 수음 → 실시간 요약 → **의사 1-tap 검수** → 종이·QR 출력

| 적용 대상 | 사용 환경 |
|---|---|
| 입원 환자 회진 / 외래 설명 | 병동 복도·병실, 인터넷 없이 단독 동작 |

출력물: A6 감열 인쇄 또는 QR (환자 휴대폰으로 열람)

## ③ 핵심 기술 및 작동 방식 (파이프라인 다이어그램)

```
[ 마이크 ]→[ 음성인식 ]→[ 임상 게이트 ]→[ LLM 추출 ]→[ 근거 검사 ]→[ 규칙 보강 ]→[ 의사 검수 ]→[ 출력 ]
 ReSpeaker   Riva ko-KR     잡담 차단       qwen3.5:2b    원문 대조      용량·일정·경고     승인 전 차단   종이/QR
  6-mic       스트리밍                       (온디바이스)   숫자 검증      원문에서 직접
```

**주행**: 2D 라이다(STL-27L) → 그래프 SLAM 지도 작성 → 지도 기반 측위 → A* 경로 → 추종 제어
ROS2 없이 순수 Python으로 구현. 엔코더 없는 차량이라 **라이다 스캔 정합 결과를 오도메트리로 사용**.

**플랫폼**: 1/5 스케일 애커만 조향 차량 · Arduino Mega 하위 제어기 · Jetson Orin NX 16GB 상위 제어기

## ④ 주요 성과 및 차별점 (수치 — 측정 조건 명시)

| 지표 | 결과 | 측정 조건 |
|---|---|---|
| 요약 **안전 정보 보존율** | **98.1 %** (52/53) | 모의 회진 대화 14건, 약 용량·일정·경고 항목 기준 |
| 요약 전체 보존율 | 94.7 % (71/75) | 동일 데이터셋 |
| 규칙 보강 전 → 후 | 34.4 % → **98.1 %** | 동일 모델·동일 데이터셋 |
| 의학용어 인식 | "메트포르민" **3/3** | 근거리 30 cm, 단어 부스팅 20 |
| 미검수 출력 차단 | **403 (100 %)** | 승인 전 출력 경로 전수 시험 |
| 라이다 | 10 Hz · 2,172 점/회전 · CRC 오류 0 % | 921,600 bps 실측 |
| 지도 작성 | 복도·교차로, 키프레임 116 | 수동 주행 1회 |

### 차별점 3가지
1. **전부 로봇 안에서 돈다.** 클라우드 전송 없음 → 대화 원문이 병원을 벗어나지 않는다.
2. **모델을 믿지 않는다.** 원문에 없는 숫자는 코드가 버리고(근거 검사), 모델이 흘린 용량·일정·경고는
   코드가 원문에서 직접 회수한다. 소형 모델의 환각을 **구조로** 막았다.
3. **의사가 승인해야만 나간다.** 미검수 상태에서는 출력·QR·인쇄가 전부 차단된다 (human-in-the-loop).

## ⑤ 활용 방안 및 기대효과

- **환자**: 설명을 종이로 가져간다 → 복약 순응도·재방문 일정 준수 향상
- **의료진**: 설명 반복·전화 문의 감소. 기록은 의사가 승인한 내용만 남는다
- **병원**: 외부 전송이 없어 개인정보 이슈가 작다. 인터넷 없는 구역에서도 동작
- **확장**: 투약 안내, 퇴원 교육, 검사 전 준비사항 안내로 확대 가능
